Active use case — follow only this path next

First 15 minutes (every login)

  1. Open AI Overview. Read Health, Active Issues, Recent Threads, Live Ops. Screenshot the thread list — that is the packaging surface you actually have.
  2. Open Connectors. Confirm GitHub + Edge Delta MCP. If a use case needs AWS / Elastic / CircleCI / PagerDuty and it is missing, stop — that UC is blocked.
  3. Open Monitors. Sort by status. Note OK vs Alert vs No Data. Click a name only to read type + notify targets — do not hit Test Notifications.
  4. Open Events. Filter last 6h. Look for K8s BackOff and event.type:pattern_anomaly (expect 0 on the latter).
  5. Open Logs / Metrics / Traces / Service Map. Set pipeline kubernetes and namespace ed-lab if the Node is sending. Default metric query is ed.pipeline.node.read_bytes.
  6. Come back to Overview. If a thread appeared, open it. If Issues is still 0, you are done — do not wait for a Dynatrace Problem twin.
