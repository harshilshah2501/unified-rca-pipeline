1.1 Dual-layer, not dual-track

In one sentence: Dynatrace and Datadog centralize-then-analyze; Edge Delta shifts processing left, then runs a standing AI team on monitors + that stream.

Dual-layer — two jobs, not a dual-track twin
Layer A · Telemetry Pipelines

Admit, parse, enrich, mask, pattern, route. Node / Gateway / Cloud. Architecture.

Layer B · AI Team

Continuous teammates. Issues package recurring problems. Overview is the operator landing page.

Not Smartscape∥Grail (two write facets). Not Metrics∥APM∥Logs (three tagged rails). Hygiene then a standing team.
