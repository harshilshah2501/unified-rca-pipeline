Deploy · what you actually install
Node → Gateway → Platform index + org Monitors → AI Team
  • Node — per-machine agent (DaemonSet).
  • Gateway — cluster hub (Deployment). Optional globally; practically required for UC4 OTLP.
  • Platform — after egress (index + org monitors).
  • AI Team — sits on that platform. Not a cluster pod.
  • Coordinator — extra, not a fourth catalog. Cluster control plane, mostly E5.
  • This lab ran Node-only for UC1 / UC8 / UC9 / UC10. Gateway is a job, not a required third SKU.

Term key: Node = per-node DaemonSet collector; Gateway = cluster Deployment aggregator; Platform index = SaaS store where logs/metrics/traces/patterns/events are queryable; org Monitors = backend thresholds/anomalies; AI Team = always-on investigation workflows.
