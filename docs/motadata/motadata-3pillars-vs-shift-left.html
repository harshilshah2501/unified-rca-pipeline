1. Which phase owns each pillar

A pillar is not a phase. Pillar A and Pillar B are always-on P1 stores. P2/P3 only read them. Pillar C runs in P3 (Clock B — diagnose/close) as optional Layer I. It is not Detect door C.

PillarOwns (write path)Read byDoes not own
A · Percentiles P1 E4 sketch store · P1 E5 seasonal refresh P2 E6 door C (thresholds) · P3 E10 get_metric_baseline() E1/E2 (needs identity first) · E9 leaf rule
B · Knowledge graph P1 E3 GraphSnapshot · P1 E5 versions / changes / writeback P2 E8 hop/time budget · P3 E9 walk · P3 E10 query_graph() E6 Detect (Alert is a node, not the detector) · E11 executor
C · Rust ReAct agent P3 E9 Localize · P3 E10 Identify · P3 E11 Package (explain/ticket) Tools read A+B via E8-bounded retrieval P1 fabric · P2 E7 Curate (keep as a stage) · remediation
P2 has no Motadata pillar. Case-open (E6–E8) is not Pillar A, B, or C. Detect door C (platform thresholds) is a consumer of Pillar A (sketches). Scope knobs are the PDF’s “RCA retrieval layer.” Curate stays a required stage (D3) in front of Pillar C — do not implement it only as deduplicate_incident().
A · Percentiles

Sketches, not Node E2

T-Digest + buckets + seasonal baseline on Vortex/S3. Consumers: dashboards, alerts, agent. Thresholds are platform Detect (door C). Seasonal update is E5 freshness. Windowing sits after the bus.

B · Knowledge graph

SaaS owns the snapshot

Typed entities and edges match “SaaS owns GraphSnapshot; Gateway only assists.” Mixes Change (E5), Alert (E6), Incident / ITSMTicket (E7/E11) into the same store. Traversal recipe is E9’s walk.

C · Rust ReAct agent

Layer I, not the clock

Observe → retrieve baseline/graph → correlate → hypothesize → validate → act. That is Localize + Identify + Package with tools. deduplicate_incident leaks into E7. execute_remediation is outside E1–E11. LLM proposes; policy authorizes. D5 stays Review.

2. Recommended implementation order

Do not ship A → B → C as three products. A and B are parallel P1 writers after E2 keys exist. C is last and opt-in (Gate D / D5 Review). Aligns with shift-left Gates A–D and LLD-E1/E2 already Done.

So: identity → stores (A+B) → detect/curate/scope → deterministic RCA → optional agent.

6. What to take vs what not to copy

Take: mergeable percentile sketches as an E4 modality; typed RCA graph with valid_from/to and confidence as E3; bounded retrieval as E8; hypothesis-plus-evidence language for E10; LLM never owns authorization if Layer I ships.
Do not copy: skipping Node E1–E2; treating NATS+Vortex as the whole product; folding Curate into the agent; making ReAct the default Package path; calling ITSM or remediation Collect.

Formal contracts stay on the Pipeline HLD. This PDF is a Motadata implementation sketch of the SaaS column, not a rewrite of the clock.
