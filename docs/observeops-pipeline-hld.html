P1 — Always-on fabric (E1-E5)

E1Collect
  • Purpose: ingest edge telemetry payloads.
  • Trigger: continuous stream.
  • Input/Output: external telemetry to TelemetryEnvelope.
  • Failure: no data enters pipeline.
E2Identity
  • Purpose: stamp join keys and ci_ref.
  • Output: IdentifiedRecord.
  • Pre/Post: configured mapping, record becomes joinable.
  • Failure: cross-modal joins break.
E3Topology
  • Purpose: maintain walkable dependency graph.
  • Output: GraphSnapshot.
  • Degradation: staleness increases ambiguity.
  • Lab proof: required for cascade/path reasoning.
E4Stores
  • Purpose: persist queryable evidence history.
  • Output: modality query surfaces keyed by identity.
  • Failure: Detect/Identify cannot corroborate.
  • NFR sketch: retention + query latency budgets.
E5Maintain
  • Purpose: keep estate fresh (retention/indexing/discovery).
  • Output: detect-ready freshness baseline.
  • Failure: quality decays silently over time.
  • Policy: explicit required stage in our HLD.

P2 — Case opens (E6-E8)

E6Detect
  • Purpose: emit fault Signal objects only.
  • Inputs: stores + topology context.
  • Failure: no automatic case opening.
  • Class plug-ins: ERROR and SLOWDOWN.
E7Curate
  • Purpose: merge signals into one CaseSeed.
  • Policy: required by default (D3).
  • Failure: storm reaches operator unfused.
  • Postcondition: one seed with rationale.
E8Scope
  • Purpose: lock time and candidate working set.
  • Output: WorkingSet.
  • Failure: global/noisy diagnosis.
  • Alias: Tailor in the 5+3+3 lens.

P3 — Diagnose and close (E9-E11)

E9Localize
  • Purpose: produce one LeafClaim.
  • Rule: deepest error leaf or longest self-time leaf by class.
  • Failure: no actionable RCA target.
  • Degradation: ranked candidates with lower confidence.
E10Identify
  • Purpose: build corroborated EvidenceBundle.
  • Failure: verdict cannot be trusted/explained.
  • Degradation: thin bundle must be marked incomplete.
  • Emphasis: stack/log/span for ERROR; self-time/CPU for SLOWDOWN.
E11Package
  • Purpose: emit operator-facing VerdictCard.
  • Policy: required close stage (D4).
  • Optional: narrative layer (Bits-style), incident payload.
  • Failure: RCA output remains engineering-only.
