MAP/ Pillar B · topology

Job: durable estate picture — who exists, how they relate.

Sub-blocks:

  • graph_node.v1 — CI vertices (tenant+ci_id)
  • graph_edge.v1 — typed arcs + discovered_via + validity
  • GraphSnapshot — versioned package of nodes+edges for a tenant
  • Optional later: change facts may live under history (see Gate B note)

Analogy: Smartscape-like map. Not sketches.

HISTORY/ Pillar A · sketches

Job: compact metric history per entity × window.

Sub-blocks:

  • sketch.v1 — T-Digest + buckets + seasonal baseline
  • Logical key: (tenant, entity_id, metric_id, window, season_key, window_start)
  • Lab object: sketches.jsonl; Motadata-shaped: S3 cold + Vortex hot
  • Optional later: exemplars on bins; change_fact.v1 sibling file

Analogy: Grail-like history path — but Detect reads sketches, not raw lakes.
