Call sequences

Use case 1 — write path

  1. load_estate_bootstrap — optional starting estate into memory
  2. write_topo_stream — admit topo lines → GraphState (not Dest yet)
  3. publish_map — validate + write snapshot / nodes / edges to Dest
  4. maintain_map — E5 validity marks — then publish_map again

Use case 2 — walk-through

  1. load_snapshot — read Dest map/ keys into a snapshot dict
  2. get_neighbors — 1-hop / multi-hop via neighbors()
  3. get_reachable — seed + neighborhood CI set via reachable_ci_ids()
  4. get_paths — simple paths via find_paths()

How the layers relate
