conflict ∥ (parallel)
Means parallel paths / simultaneous writes — not “next step in a sequence.”
conflict Scope ≡ Tailor
Same job (lock entities + time for diagnosis). HLD calls it E8 Scope; DT/Clock A teaching often says Tailor. Glossary treats them as aliases.
conflict leaf (DT) vs Leaf (DD)
DT teaching: deepest topo tip on the call path (often the seed preference). DD stage 07: localize claim by Detect class (deepest error span or longest self-time) — Map ≠ Leaf.
conflict Verify vs Package
NAV workflow ends in Verify; vendor compare often folds Verify/Package. HLD has E11 Package without a separate Verify block.

Our HLD (ObserveOps)

Canonical: observeops-pipeline-hld.html · OBSERVEOPS_PIPELINE_HLD.md

Layers

ours Layer E · Engineering
Required fabric + case pipeline (Collect through Package). Writes, Detect, scope, localize, package.
ours Layer I · Interpret
How a human (or Bits-like agent) reads one Observed run — Timeline, MTL workbook, Bits. Not a storage or Detect engine.

Blocks E1–E11

ours E1 Collect
Edge intake → raw / near-raw payloads.
ours E2 Identity
Join-ready records (tags and/or entity id).
ours E3 Topology
Walkable neighbors + edges (typed graph or derived — LLD decision).
ours E4 Stores
Queryable history under Identity (not forced to one Grail).
ours E5 Maintain
Retention, indexing, discovery freshness, version/deploy change feed — fresh fabric for Detect.
ours E6 Detect
Fault signals only — not a ranked root cause.
ours E7 Curate
Collapse a storm of signals into one case seed.
ours E8 Scope
Lock time window + candidate set for diagnosis (alias of Clock A Tailor).
ours E9 Localize
Leaf claim — rule depends on Detect class (deepest error vs longest self-time, etc.).
ours E10 Identify
Ranked multimodal evidence bundle around the leaf.
ours E11 Package
Operator verdict card; Bits-style narrative optional on top.

Other Ours terms

ours MTL workbook
Layer I: Metrics ∥ Traces ∥ Logs queries/counts for one Observed window.
ours Bits (Interpret)
Layer I packaging walk / optional E11 narrator — not Collect/Detect fabric.
ours D1–D5
Open HLD decisions (topology style, stores, Curate strength, Package policy, AI placement).

Clock A / Clock B (shared teaching lens)

Optional pattern vocabulary after reading each vendor natively. See also clock-ab-stage-reference.html.

Clock A
Always-on fabric + case open: Collect → … → Maintain → Detect → Curate → Tailor. (Datadog remaps Maintain → continuous 03 Write.)
Clock B
Diagnose after Tailor working set: Localize → Identify → Package (Lean vs Fed algorithms).
5+3+3
Teaching split: 5 always-on · 3 case-open · 3 diagnose (DT-oriented).
Always-on fabric
Continuous write with no incident yet (Collect through Maintain / DD Write).
Case opens
Something crossed a line: Detect → Curate → Tailor/Scope.
seed
Curate handoff tip (entityId, t0) — not yet the packaged root cause.
storm
Pile of raw Detect signals before Curate merges them.
cascade
Failure spreads along callers (FE→product→inventory); many symptoms, one leaf.
working set
Tailor/Scope output: entities + time range for Localize/Identify.
symptom seed
Where pain showed — start of search, usually not the root.
parity-shared-detect
Bakeoff: same alerts to both engines; score Localize only.

Event / Problem

dt Event
One Detect breach record for an entity+time. Not a Problem.
dt Problem
Packaged RCA card after Curate→Tailor→Davis (may still have rootCauseEntity=null).
dt Event ≠ Problem
Core teaching invariant.
dt rootCauseEntity
Packaged entity RC on the Problem; null when Events align / ranking weak.
dt rootCauseRelevant
Per-evidence flag on contributing Events.
dt leaf (topo)
Deepest service on the call path (inventory in the lab) — preferred seed tip; timing ≠ role.
dt same start bucket
Events share the same start minute → often weak temporal leaf ranking / null entity RC.
dt discovery-first
Smartscape from observed traffic; CMDB optional enrich, not required.

Datadog hub

Hub: dd-detect-category-hub.html · Thesis · Breakdown · Three-rail · Timeline · Interpret (MTL · Bits)

Eight stages (no Maintain)

dd 01 Agent
Edge collect: host/container sources ∥ application sources (ddtrace, DogStatsD, log tails) → Datadog intake. Lab does not push via Datadog HTTP REST.
dd 02 Tagging
Unified Service Tags (service · env · version · host) for join.
dd 03 Write (M ∥ APM ∥ Logs)
Continuous write of the three rails into Metrics timeseries ∥ Husky events. Includes live baseline — not Detect.
dd 04 Service Map
APM-derived peers — topology only; Map ≠ Leaf.
dd 05 Monitors · Watchdog
Detect via two independent Doors (or empty foghorn).
dd 06 Triage · Related
After Detect (or when Detect is empty): pick the primary symptom card / window and lock env · version · time.
dd 07 Leaf · tag join
Name the causal tip on the flamegraph / spans, then corroborate across rails by tags (+ trace_id).
dd 08 Bits ∥ Incident
Optional packaging; Incident often 0.

Edge emitters (lab → Agent)

dd ddtrace
Python APM library: spans → Agent Trace intake (:8126). Feeds the APM rail, Service Map peers, and APM-derived metrics. Lab: from ddtrace import tracer in telemetry.py.
dd DogStatsD
UDP custom metrics to Agent (:8125). Lab counters like rca.inventory.stock.errors / …ok — Metrics rail, not APM spans. Separate from ddtrace.
dd JSON logs (+ dd.trace_id)
Stdout / file tails via Agent log config. Same Unified Service Tags; dd.trace_id joins a log line to its span.

Rails · Doors · Triage · Leaf

dd rails / three-rail
Operator UI evidence channels: Metrics ∥ APM (Traces) ∥ Logs, joined by Unified Service Tags. Backend: Metrics timeseries ∥ Husky (traces + logs). Teaching page: Three-rail. Not Dynatrace dual-track (Smartscape ∥ Grail).
dd Doors
Two parallel Detect entries at stage 05 — independent; either, both, or neither may fire. Door ≠ Bits ≠ Incident.
dd Door A · Monitors
Explicit query + threshold (pack- or user-authored). Lab ERROR: Flask High Error Rate (310925690, min(last_15m)). SLOWDOWN: same error Door stays OK on HTTP 200; a latency/p95 Door A was never scoped → no Alert.
dd Door B · Watchdog
Anomaly stories (source:watchdog) without that hand-written query — APM and/or Logs Insights; optional APM bridge monitor (310485027). Lab SLOWDOWN: 0 APM Watchdog stories.
dd Triage
Stage 06: choose which symptom is primary (hot Door card, Insights, or — when Detect is empty — an operator-chosen latency window) and lock scope (env / version / UTC range) before Localize. Not Curate/Problem merge.
dd Leaf
Stage 07 localize claim: the span/resource where work actually fails or burns time — not Service Map red, not the first Door alert. ERROR → deepest status:error span; SLOWDOWN → longest self-time (lab: inventory.stock). Then tag-join corroboration across rails. No rootCauseEntity field.
dd self-time
Time spent inside a span (vs wall time waiting on children). SLOWDOWN Leaf rule.

Core teaching rules

dd Write ≠ Detect ≠ Localize
Loud explorers (03 Write / rails) ≠ Door Alert (05) ≠ naming the Leaf (07). SLOWDOWN Observed: Write loud, Detect empty, operator Triage + Leaf.
dd Detect ≠ Bits ≠ Incident
Door Alert/story ≠ Bits Investigation ≠ Incident card.
dd empty Detect / foghorn
Stage 05 quiet while stage 03 has data. Foghorn = teaching word for “a Door fired,” not a product name.
dd Metrics timeseries ∥ Husky
Backend stores behind the three rails: classic Metrics store separate from Husky Event Platform (traces + logs).
dd Unified Service Tags · tag join
Join Metrics ∥ APM ∥ Logs by tags (+ trace_id for log↔span).
dd Engineering vs Interpret
Hub chrome: Thesis/Breakdown/Three-rail/Timeline = engineering; MTL/Bits = Interpret one run.
dd IPO
Input → Processing → Output shape on Breakdown stage blurbs.
dd env:rca-lab-e3
Primary teaching environment tag (retire bare rca-lab / rca-lab-e2 for Observed e3).
dd live baseline · warm discovery
Healthy pre-break write (what normal looks like) · catalog/map already known from prior traffic. Taught at stage 03 Write, not 05.

Observability 1.0 / 2.0 / 3.0

Scorecard: observability-generations-dt-dd.html

1.0 Three pillars
Separate stores; many questions fixed at write-time; manual join; threshold Detect.
2.0 Wide events
Wide-event primary evidence; late binding; fabric/entity join; entity/event UX — not “any correlation.”
3.0 AI assist
Anomaly Detect first-class; default RCA package; less babysitting — not “has Watchdog or Bits.”
correlate ≠ 2.0
1.0 already correlates alerts/metrics; 2.0 is an evidence-model claim.
AI surfaces ≠ 3.0
Optional Watchdog/Bits/Davis AI ≠ clean generation-3 match.
Pass / Partial / Fail · hybrid
Scorecard language; DT and DD score as hybrids (not clean 2.0 or 3.0).
C1–C4
Must-pass criteria ids per generation on the scorecard page.
