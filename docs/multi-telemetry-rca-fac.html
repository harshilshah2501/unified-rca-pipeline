Core idea — one picture

Operator sees one incident with root-cause CI, cross-telemetry evidence, and blast radius — not fifty alarms across five tools.

Key concepts

Signal

Normalized observation: type, ci_ref, time, severity, state, signature, attributes.

Entity resolution

Raw record → exactly one CI (or unattributed queue).

Correlation window

Time bound for grouping related signals.

Root-cause CI

Named cause CI + originating signal(s).

Evidence

Contributing signals across types supporting the cause.

Blast radius

Downstream impact CIs with evidencing signals.

Incident

Single output: RC + evidence + blast radius + timeline.

Assumptions & open questions

Assumptions: collectors already produce raw telemetry; Discovery/CMDB topology is reasonably complete (RCA quality ∝ topology); clocks NTP-synced within skew bound.

Dependencies: unified Signal ingest · shared entity/topology · AIOps anomaly primitives · Alert Policy & Event Correlation as incident surface.
