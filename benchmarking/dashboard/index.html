Newcomer guide

This console is the PoC control plane for Unified RCA: one shared ingest fabric, then two analyzers — Lean (primary) and Federated (comparator). Click any stage below to learn what it does.

How to read this PoC

  • 1 Ingest first. Telemetry (Motadata dumps, ObserveOps UC packs, or lab synthetic) is normalized to ingest.v1, then fanned out to Lean-only (L0) or dual sinks (F1).
  • 2 Shared Detect. Threshold crossings raise a symptom seed (A-SEED) before either engine localizes.
  • 3 Lean vs Federated. Same incident packs; Lean walks topology + signatures; Federated uses Murphy (+ optional fusion). ADR-001 keeps Lean primary for classic infra.
  • 4 What to click next. Use PoC Conduct to run jobs, then Overview / UC bakeoff for scored evidence — not marketing slides.

Glossary: CI = configuration item · L0 = Lean sinks only · F1 = Lean + structural + speed · EPS = events/sec (capacity, not accuracy).

    Evaluation finding

    Aligned with ADR-001 — bakeoff evidence favors lean for classic-infra evaluation; federated remains a valid comparator and hybrid candidate.

    Where lean leads

    • Bit-stable reproducibility on UC bakeoff (100% vs ~40%)
    • Auditable tiers / CARE / SRE trail (Verifiability)
    • Respects Roadblock 5 — cheap main path
    • Motadata L1: same 3/3 root+sig pass as Federated on inventory packs

    Where federated matters

    • Murphy partial structural / counterfactual-style CV
    • Soft ranking via causal posterior over candidates
    • Same 5/5 UC accuracy — CV did not buy extra top-1 on that GT track
    • Comparator on Motadata L1 (tie on root+sig)
